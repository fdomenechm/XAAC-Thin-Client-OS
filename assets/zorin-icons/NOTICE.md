# Zorin icon subset

The files under `ZorinBlue-Light/` are a small subset of the Zorin Icon Themes,
selected for the icon names used by XAAC Thin Client.

Upstream: https://github.com/ZorinOS/zorin-icon-themes
License: CC BY-SA 4.0 (see `LICENSE` in this directory).

Files copied from the upstream `Zorin` and `ZorinBlue-Light` themes retain their
upstream licensing. The XAAC-generated `index.theme` only describes this local
subset and falls back to Adwaita/hicolor for names not bundled here.
