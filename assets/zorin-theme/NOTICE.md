# ZorinBlue-Light GTK theme snapshot

This directory contains the GTK 3/GTK 4 portions of the `ZorinBlue-Light`
theme copied from the development workstation visual-assets export supplied
for the XAAC Thin Client OS visual-parity work.

Only the files required to reproduce the GTK appearance are retained. The
builder installs them under `/usr/share/themes/ZorinBlue-Light`.
