## Principis operatius

- L'usuari final treballa exclusivament en la sessió `xaac-kiosk`.
- L'administració local correspon a `xaac-admin`; l'accés remot ha de ser temporal i restringit.
- Tots els canvis han de ser traçables i, quan siga possible, transaccionals.
- Una incidència no es considera tancada fins validar arrencada, serveis, xarxa i quiosc.
